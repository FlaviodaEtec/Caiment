# CAIMENT - Landing Page
A plataforma **CAIMENT** é um provador virtual que transforma a experiência de comprar roupas pela internet. Com Inteligência Artificial e tecnologia 3D, o cliente consegue visualizar como a peça ficará em seu próprio corpo antes de comprar.

## Sobre o Projeto
O projeto foi criado com a intenção de ser uma solução inovadora para compras online de roupas, que ainda geram insegurança, principalmente na escolha do tamanho. 
Isso resulta em muitas trocas e devoluções, causando prejuízos para as empresas e desperdício de produtos.

A CAIMENT utiliza tecnologia para tornar a experiência de compras mais interativa e precisa. Nossa proposta não é substituir a loja física, mas levar parte da experiência do provador para o ambiente digital.
